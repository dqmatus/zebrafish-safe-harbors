## What this is

We're adapting this genomic-safe-harbor knock-in pipeline to **KNIT editing** — a
nickase-based large-cargo insertion method (Gao et al., *Nature* 2026,
doi:10.1038/s41586-026-10819-7). Goal: knock actionable multi-kb cassettes **directly
into predicted safe harbors in F0**, skipping the current landing-pad → F1 → RMCE loop.

## How KNIT works (the mechanism that drives every design choice)

- **KE1** = a fusion protein, **nCas9(D10A)–mSA** (SpCas9 D10A nickase fused to
  monomeric streptavidin), plus a **biotinylated dsDNA donor**. The nickase makes a
  single-strand nick and stays bound; the fused mSA captures the donor's 5′ biotin and
  tethers it at the nick → single-nick HDR (RAD51/BRCA2-dependent). 0.7 to >10 kb, low
  indels/translocations, DSB-free.
- **KE2** = KE1 + SunTag (24×GCN4 array + scFv–mSA) to recruit multiple donors; a later
  efficiency upgrade, not the starting point.
- All paper data is cultured mammalian cells — **no embryo/zebrafish data exists**, so
  the core scientific risk is whether single-nick tethered HDR gives usable rates in the
  early embryo (de-risk plan in `KNIT_ADAPTATION.md`).

## Why this pipeline is ~90% ready — only TWO things change

1. **Editor:** swap SpCas9 protein → **nCas9(D10A)–mSA** in the RNP (lab already uses
   Cas9-protein RNP, so format is unchanged; pre-mix biotin donor with the RNP so the
   tether pre-forms before injection).
2. **Donor 5′ end:** re-order each donor ultramer with **`/5Biosg/` (5′ biotin)** in
   place of **`/5AmMC6/`** (keep the 5′ phosphorothioate + 3′-P). Same HA, same guide,
   same cassette.

Everything else carries over unchanged: safe-harbor site selection; the single NGG
guides (**a nickase uses the identical sgRNA**); the 45 bp homology arms (KNIT validated
to 25 bp); the StayGold cassette + DM416/417 priming; and all genotyping/junction primers.

## Reagent critical path (the one genuinely new item)

The editor is **not on Addgene** (Supp Table 2, all "this paper"), but the **full KE1/KE2
protein sequences are published** (Supp Note 5) — so **synthesize, don't wait on the lab**:

- Sequence: `results/knit_editor_protein_sequences.fasta` (KE1 = 1,574 aa,
  `NLS-nCas9(D10A)-NLS-linker-mSA-NLS`; D10A + mSA verified. KE2 included.)
- Build: reverse-translate + codon-optimize KE1 for *E. coli*, gene-synthesize, clone
  into **pET28b w/ C-terminal 6×His** (`pET28b-NLS-SpCas9D10A-NLS-mSA-NLS-6×His`).
- Purify (Supp Note 4): Rosetta BL21(DE3) → Ni-NTA (60 mM wash / 250 mM elute) →
  Mono S 5/50 → Superdex 200 (S200: 300 mM NaCl, 20 mM Tris pH 7.5, 10% glycerol,
  1 mM TCEP). Standard SpCas9-grade prep. **Commercial D10A nickase will NOT work — the
  mSA fusion is the tether.**
- mRNA delivery of the same ORF is also validated in the paper if a "just add mRNA"
  route is ever preferred, but RNP matches the current protocol.

## Controls / benchmark / the AZD caveat

- **Benchmark = current SpCas9-RNP + `/5AmMC6/` donor (DM418–423) *with* AZD-7648**, at
  the same loci — the honest bar KNIT must beat. Those donors are already ORDERED, so
  it's a clean matched head-to-head (same guide/cassette/locus).
- **AZD caveat:** AZD-7648 boosts the current protocol because it's a DSB/NHEJ lever; the
  paper tested AZD-7648 (1 µM) with KNIT and saw **no consistent nick benefit**. Keep it
  as a ±arm only (embryo nick→DSB conversion might help); the real KNIT efficiency lever
  is KE2, not inhibitors. If pushing pharmacologically, try AZD + Polθi (novobiocin/ART558).
- **Readout unchanged:** StayGold + existing 5′/3′ junction PCR (DM426–435 / DM442–447).
